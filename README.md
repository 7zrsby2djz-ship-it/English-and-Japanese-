# 英日教室入口

一個按鈕，回到你自己的 ChatGPT 英日教學對話。

- **每天用的網址**：https://7zrsby2djz-ship-it.github.io/English-and-Japanese-/
- **設定頁（請加書籤）**：https://7zrsby2djz-ship-it.github.io/English-and-Japanese-/setup.html

## 怎麼用

1. 第一次：打開上面的網址 → 會自動到設定頁 → 貼上你原本教學對話的網址 → 按「儲存並進教室」。
2. 以後每天：打開網址 → 按「開始今天的課」→ 在 ChatGPT 裡打「開始」。
3. 累了：跟老師說「3分鐘」。看不懂：回 E。猜的：就說猜的。

網站只負責「帶你回到同一個教室」。出題、記進度、決定今天上英文還是日文，都是 ChatGPT 老師在對話裡做。網站不會自動送訊息，也不知道你今天上完沒有。

## 要知道的事

- 網址只存在**這支手機的這個瀏覽器**。換手機、換瀏覽器或清除瀏覽資料，要再設定一次（打開設定頁貼網址即可）。
- 要換教室：打開設定頁，貼新網址再儲存。
- 「清除入口設定」只刪掉這個網站記住的網址，不會刪 ChatGPT 的任何東西。
- 加到主畫面：在 Safari 按分享 →「加入主畫面」。按圖示會用 Safari 打開，跟設定共用同一份記錄。
- 這個倉庫是**公開**的，所以私人教材（兩本聖經、合併啟動包、進度、答案）**沒有**放進來。請自己保管 ZIP；新開教室時才把「合併啟動包」附給 ChatGPT。

## 還要你自己在 iPhone 上確認一次

電腦模擬測過了，但下面這些只有你在手機上能確認：

- 按「開始今天的課」後，有沒有打開**你原本那個**教學對話（不是新的空白對話）。
- 從 Safari 網址列複製對話網址順不順。
- 加到主畫面後，圖示打開正不正常。
